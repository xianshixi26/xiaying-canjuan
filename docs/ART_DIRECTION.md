# 《侠影残卷》美术方向（ART_DIRECTION）

> 视觉参考：设计者提供的国风工笔淡彩图（灰瓦红墙、柳树石板路）。**红线（D-008）：只借鉴构图、材质、色光，不复制任何现有作品的角色、地图、界面与素材。**
> 更新日期：2026-11-08（D-020）

## 1. 核心视觉原则（符合/偏离本作的判据）

1. **工笔淡彩 + 写意留白**：物体造型准确可辨（瓦片、树种、石材），色彩低饱和淡彩平涂，边缘保留笔触感；不做卡通描边、不做像素风。
2. **温润纸本**：画面基调为暖米色纸本质感；禁止大面积纯灰、纯黑、纯白。
3. **朱红点睛**：高饱和红只用于灯笼、檐饰、印章、花朵，作为视觉焦点；其余一律低饱和。
4. **剪影可辨**（俯视）：屋=灰瓦梯形+脊线，柳=垂丝放射，松=层叠伞形，石=灰块+苔绿——一眼可分辨。
5. **疏密有致**：广场与空地留白；大树/大屋做视觉锚点；细节密度物件 > 地面。

## 3. 材质与笔触规则

- 平涂底色 + 两级明暗（受光偏暖亮、背光偏冷暗）+ 细节线条（瓦行、木纹、叶脉、石缝）。
- 所有边缘允许 1-2px 手绘抖动；禁止纯几何直线。
- 地面：石板=不规则石块+灰缝；草地=绿色晕染斑块+草叶笔触+小花点；纸地=纤维颗粒+淡墨晕。

## 4. 物件识别特征

| 物件 | 标志性特征 |
|---|---|
| 村屋 | 灰瓦大屋顶（瓦行+檐口扇贝边+脊线两端红饰），红墙或白墙，石基座，红灯笼 |
| 柳树 | 弯曲褐干 + 放射状垂丝（带叶点），冠下留空 |
| 松树 | 三层伞形冠（深绿+亮边），直干 |
| 岩石 | 灰色块面 + 苔绿斑 + 墨线轮廓 |
| 池塘 | 青灰水面 + 横向波纹笔触 + 波光短线 |
| 小径 | 石板拼块，暖灰色，灰缝清晰 |

## 5. 构图与疏密

- 村中心广场留白（纸地）；建筑沿小径排列；大树置于拐角做地标；池塘占一角。
- 单屏内大物件 3-5 个，中物件 8-15 个，小点缀 20+，避免均质。

## 6. 关键游戏时刻（视觉风险最高的战斗反馈）

- 刀光：纸白色宽弧 + 墨色细弧双描边；重击红色宽弧。
- 受击：整体闪红 0.2s + 击退位移；敌人头顶血条（深墨底 + 朱红条）。
- 领悟提示：宣纸底横幅 + 墨框 + 朱红"✦"标记，居中上方，与场景对比度充足。
- 不依赖颜色辨识：所有敌对信息同时有形状提示（红头巾/血条）。
