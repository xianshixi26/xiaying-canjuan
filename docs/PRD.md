## 2. 核心玩法

### 2.1 组合招式系统（游戏灵魂）

三层按键结构：

**第一层：基础键**

| 键位（草案） | 基础动作 | 说明 |
|---|---|---|
| WASD / 方向键 | 移动 | 8 方向移动 |
| J | 攻（轻击） | 快速攻击，可连按 |
| K | 破（重击/破防） | 打架势/破防，出手慢、伤害高 |
| L | 闪（位移） | 冲刺/翻滚，含无敌帧 |
| U | 御（格挡/架势） | 减伤；精准时机触发弹反窗口 |
| I | 气（内力技） | 消耗内力的特殊动作 |

> 键位最终以制作期"按键确认"一问为准，且支持玩家重绑定。

**第二层：组合招**（按键序列 + 方向 + 节奏）

| 组合示例 | 招式（示例名） | 阶位 | 解锁方式 |
|---|---|---|---|
| 攻-攻-攻 | 三连斩 | 低阶 | 自由摸索 |
| 方向 + 攻 | 突刺 / 撩斩（随方向变化） | 低阶 | 自由摸索 |
| 闪 + 攻 | 追影刺 | 中阶 | 自由摸索 |
| 御 + 攻（精准时机） | 防反·回风拂柳 | 中阶 | 摸索或秘籍 |
| 气 + 方向 | 剑气纵横（远程） | 高阶 | **秘籍解锁** |
| 攻-攻-破-气 | 终结技·沧溟一现 | 高阶 | **秘籍解锁** |

规则：
- **摸索发现**：玩家输入新的有效序列时，弹出"领悟招式"提示并收录进招式图鉴（悟性影响发现概率与提示力度）。
- **秘籍解锁**：高阶组合招必须装备/研读对应秘籍后才可使用。
- 两者结合（决策 D-003）。

**第三层：连招链（自创武功）**
- 玩家把已收录的招式**自由编排**为连招链（起手 → 追击 → 终结），保存多套方案可随时切换。
- 连招链容量受**悟性**影响（低悟性 3 段，高悟性上限更高，数值制作期定）。
- 这是"创造属于自己的武侠招式"的核心落地。

### 2.2 战斗系统

- 即时战斗（非回合制），俯视角多方向作战。
- 双资源：**气血**（HP）+ **内力**（驱动"气"与高阶招式）。
- 架势博弈：「御」减伤/弹反，「破」破防，防反高回报，鼓励主动进攻。
- 敌人类型：人形（山贼/幽泉教众/宗门弟子）、野兽、Boss。
- 敌人 AI：追击、包围、低血逃跑、呼援（基础行为树/状态机）。

### 2.3 探索系统

- 俯视 2D，Tilemap 分块拼接地图。
- 区域规划：

| 区域 | 定位 | 备注 |
|---|---|---|
| 落雁村 | 新手村 | 主角故乡，序章剧情 |
| 黑风林 | 初始野外 | 山贼、野兽、基础材料 |
| 望月城 | 城镇 | 商店、委托板、NPC 情报 |
| 六大宗门 | 门派地图 | 拜师、门派任务、专属商店 |
| 幽泉坛 | 后期敌营 | 主线后期 |
| 秘境（数个） | 高难高掉落 | 隐藏区域，稀有秘籍/材料 |

- 拾取物四类（决策 D-006）：**武器、药品、秘籍、材料**。
- 宝箱、隐藏点、采集点分布在探索路径上。

### 2.4 昼夜系统（V1 包含）

- 游戏内时钟（初始建议：现实 10 分钟 = 游戏 1 天，可调）。
- **夜晚更危险**：敌人属性提升、夜行敌人（伏击者/亡魂类）出现、敌人刷新增多。
- **夜晚补偿**：掉落品质提升、部分材料/事件/商店仅夜晚出现，风险与收益对等。
- 主线有剧情节点强制时间推进。

### 2.5 属性系统（决策 D-004）

六维基础属性：

| 属性 | 影响 |
|---|---|
| 力道 | 外功伤害、负重 |
| 身法 | 攻速、移速、闪避、闪招无敌帧 |
| 根骨 | 气血上限、防御、抗毒 |
| 悟性 | 秘籍修习速度、连招链容量、摸索发现概率 |
| 内力 | 内力上限、回复速度、内功伤害 |
| 气运 | 掉落品质、命格抽签、随机事件 |

派生属性：气血（根骨）、内力值（内力）、攻速（身法）、防御（根骨）等。
成长：升级获得自由属性点 + 命格修正；秘籍可永久加属性。

### 2.6 开局命格抽签（决策 D-005）

- 包装为**卦象抽签**：序章在破庙中向神秘高人抽一支签（非现代转盘）。
- 每个存档**一次机会**，结果随机，决定初始属性修正与特性。
- 品质：凡品 / 地品 / 天品 / 隐藏命格。
- 示例：
  - 「武曲星临凡」（天品）：力道 +3，破招伤害 +10%
  - 「扫地僧命格」（天品）：悟性 +3，摸索发现率 +20%
  - 「夜猫子」（地品）：夜晚战斗属性 +10%，白天 -5%
  - 「天煞孤星」（隐藏）：全属性 -1，但掉落品质大幅提升（高风险高回报）
- 可重开存档刷命格，增加重玩价值。

### 2.7 物品与装备（决策 D-006）

- **武器**：刀（刚猛）/ 剑（均衡）/ 拳掌（贴身快打）/ 暗器（远程）/ 棍（范围控场）。
  - **武器类型改变可用招式组**（换武器 = 换打法）：五类武器各有**独立招式组**与基础攻击参数（伤害/范围/攻速），同一按键序列在不同武器下施展不同招式（如 J-J-J：剑=三连斩 / 刀=劈山式 / 棍=横扫千军）。
  - 武器获取：正式版由拾取/装备驱动；原型期数字键 1-5 切换以便测试。
- **药品**：金疮药（回血）、回气散（回内）、解毒药、临时增益药。
- **秘籍**：解锁高阶组合招 / 永久属性。
- **材料**：锻造（强化武器）、制药合成。
- 背包 + 战斗快捷栏（4 格药品栏，可调）。

### 2.8 宗门系统（决策 D-007）

| 宗门 | 特色 | 武学方向 |
|---|---|---|
| 少林 | 僧兵、刚猛 | 拳、棍 |
| 武当 | 道家、以柔克刚 | 剑、内功 |
| 峨眉 | 身法灵巧 | 剑、轻功 |
| 唐门 | 机关毒药 | 暗器、毒 |
| 丐帮 | 情报遍天下 | 棒法、杂学 |
| 华山 | 剑宗正统 | 剑法 |
| 幽泉教（敌对） | 邪派，主线反派势力 | 诡道、刺杀 |

- 拜师：满足条件（声望/任务）可入门，解锁门派专属招式、商店、任务。
- 声望系统：各宗门独立声望，影响商店价格、剧情分支、结局。

### 2.9 剧情（详见 §3）

- 主线四幕 + 结局分支。
- 支线：宗门支线、望月城委托板任务。

## 3. 剧情设计（决策 D-008）

**世界观**：架空王朝「大虞」，朝堂衰微，江湖纷争。传说绝学《沧溟诀》早已失传，只余残页散落江湖，据说集齐可参破武学至高之境。

**主角**：无名孤儿（玩家命名），自幼被隐居落雁村的老剑客"醉剑"**秦无咎**收养——一个整日酗酒、只教"庄家把式"的落魄老头。

**第一幕·起祸**
主角生日当晚，神秘黑衣人血洗落雁村，目标是师父房中一页残卷。师父力战而亡，临终留下一句没头没尾的话："别信……穿白衣服的……"，和半页残卷。主角埋葬师父，踏入江湖。

**第二幕·入局**
主角闯荡江湖（探索、宗门、秘境均在此展开），追查残卷下落，发现师父之死牵出二十年前的公案：**幽泉教**正在搜集《沧溟诀》残页，教主**殷无昼**欲以此功称霸武林。途中主角屡被一位神秘贵人相助——听风楼楼主**白霁**，温文尔雅的白衣情报商人，提供关键线索，成为主角最信赖的盟友。

**第三幕·诛邪**
主角集结各宗门力量（宗门声望系统发挥作用），攻破幽泉教总坛，手刃殷无昼——大仇得报，江湖称颂。（玩家以为至此通关。）

**第四幕·反转（真相）**
战后主角在幽泉教密室发现殷无昼的绝笔与往来书信，惊觉真相：
> 幽泉教搜集残页，从来不是为了自己——殷无昼只是被推上前台的棋子。真正的幕后黑手是一路"指引"主角、借主角之手铲除幽泉教的白衣贵人**白霁**；而白霁效忠的主人，是主角那"死去"的师父**秦无咎**。

原来秦无咎与殷无昼本是同门师兄弟，同修《沧溟诀》各得一半。秦无咎当年假死，以主角为刀除掉师弟夺回另一半，再让白霁引导主角集齐所有残页——主角一路的成长、复仇、行侠仗义，全在老狐狸的棋盘之上。师父那句"别信穿白衣服的"，是他留给主角的唯一一丝真心。

**结局分支**（玩家最终选择）：
1. **诛心**：手刃师父，毁去《沧溟诀》——江湖再无此祸，主角隐入山林。
2. **释然**：废去师父武功，囚于落雁村坟前守墓，残卷归还各宗门。
3. **入魔**（隐藏线）：夺走完整《沧溟诀》自行修炼，成为新的"幕后之人"，开启二周目新内容。

反转设计意图：反派是玩家最信任的人，二周目重玩时所有前期对话都会变味（师父的"教诲"、白霁的"热心"全是伏笔）。

**原创性红线**：世界观、人物、组织、情节全部架空原创；少林武当等仅取现实历史文化的通用概念；不得使用任何现有小说/影视/游戏的角色、情节、专有设定、素材。

## 5. 技术需求

- Godot 4.x + GDScript。
- **架构约束（为联机预留，决策 D-009）**：游戏逻辑（状态、战斗计算、存档数据）与渲染/输入解耦；游戏状态可序列化；随机数可控（可指定种子）。V1 不写联机代码。
- 存档：本地多存档槽（JSON/ConfigFile）。
- 设置项：音量、按键重绑定、分辨率/全屏。
- 性能目标：1080p 60fps。

## 6. 阶段规划（Roadmap）

| 阶段 | 内容 | 阶段验收标准 |
|---|---|---|
| Phase 0 | 项目初始化（Godot 工程/目录规范/Git） | 空场景可运行，工程结构就绪 |
| Phase 1 | 核心移动 + 战斗原型（灰盒） | 移动/攻击/破/闪/御可玩，敌人有基础 AI |
| Phase 2 | 组合招式系统 | 摸索发现 + 秘籍解锁 + 连招链编辑器可用 |
| Phase 3 | 探索 + 物品 + 属性 + 命格 | 拾取/背包/属性成长/开局抽签完整循环 |
| Phase 4 | 昼夜 + 剧情 + 宗门 | 主线四幕可通关（含反转与结局分支），昼夜生效 |
| Phase 5 | 轻功 | 轻功位移/跳跃地形可用 |
| Phase 6 | 联机（V2） | 双人合作探索稳定 |

每阶段验收通过后打 Git tag `phase-N-done`。
