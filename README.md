## 快速开始

1. 运行 Godot 4.7.2（`D:\Godot\Godot_v4.7.2-stable_win64.exe`），导入本目录的 `project.godot`；
   或命令行直接运行：`Godot_v4.7.2-stable_win64.exe --path <本目录>`
2. 在编辑器中按 **F5** 运行主场景。
3. 操作：**WASD** 移动 ｜ **J** 攻 ｜ **K** 破 ｜ **L/Shift** 闪（无敌帧） ｜ **U** 御（按住减伤） ｜ **I** 气 ｜ **1-5** 切换武器（剑/刀/拳掌/暗器/棍） ｜ **Tab** 武学图鉴。
4. **武器决定招式**：同一套连招在不同武器下是不同招式——J-J-J：剑=三连斩 / 刀=劈山式 / 拳掌=连环掌 / 暗器=漫天花雨 / 棍=横扫千军；终结技也各异（J-K-I 或 J-K-K，见图鉴）。首次使出会"领悟"并收录图鉴。
5. 当前地图：**落雁村**（垂直切片第一图）——纸地/草地/小径/池塘、村屋、林带、篱笆，水墨风素材为程序生成（`tools/gen_assets.py`，D-019），可整体替换为手绘素材。
