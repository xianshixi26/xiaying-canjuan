## 快速开始

1. 运行 Godot 4.7.2（`D:\Godot\Godot_v4.7.2-stable_win64.exe`），导入本目录的 `project.godot`；
   或命令行直接运行：`Godot_v4.7.2-stable_win64.exe --path <本目录>`
2. 在编辑器中按 **F5** 运行主场景。
3. 操作：**WASD** 移动 ｜ **J** 攻 ｜ **K** 破 ｜ **L/Shift** 闪（无敌帧） ｜ **U** 御（按住减伤） ｜ **I** 气（剑气，耗内力） ｜ **Tab** 武学图鉴。
4. 连招（时间窗口内依次按下）：J-J-J 三连斩 / J-J-K 挑山式 / K-J 断岳 / L-J 追影刺 / U-J 防反·回风拂柳 / I 剑气纵横 / J-K-I 终结·沧溟一现。首次使出会"领悟"并收录图鉴。
5. 画面为水墨风占位图形（宣纸底 + 墨点 + 印章红），正式美术素材后续制作。
